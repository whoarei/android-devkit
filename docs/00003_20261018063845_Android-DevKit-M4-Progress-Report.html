1. 本轮完成的功能

领域最终行为
Logcat 与应用过滤解析 threadtime 的时间、PID、TID、级别、Tag、正文；支持级别、Tag、关键词、PID 和应用包名过滤。每 2 秒刷新主进程与冒号子进程集合；进程变化写入采集段 / 缺口提示，不将等待进程伪装为没有日志。
缓冲与视图10,000 行 / 8 MiB 原始文本上限，单行有界；只渲染末 500 行。暂停只冻结视图，清空建立序号游标，不执行 logcat -c；恢复显示缓冲淘汰缺口。
文件采集独立持久任务，切页继续；总配额 8～4096 MiB、时限 1～86400 秒，每段最多 100 MiB。达到配额 / 时限或主动停止后封口、校验并保存清单；连接、进程变化、缓冲超限和磁盘问题保留缺口。
导出与隐私当前过滤范围、所选采集段、环境诊断分别准备。默认替换用户目录、设备标识、IP 和常见秘密字段；实际输出按 300 行分页预览。原始内容须明确选择。单次导出最多 64 MiB，超限标记截断，可分批选择。
产物与退出SQLite 保存未另存产物。保存先写临时文件并核对内容，再提交到选择位置；失败不标成功。无任务 / 未保存产物时正常退出，否则统一提示。明确放弃只绑定当前展示的产物 ID；收尾产生新截图时再次提示。
托盘与调度托盘默认关闭，显式启用后关闭窗口隐藏；可恢复窗口或走统一退出。菜单 / 提示显示任务数与需检查数。不同设备写任务最多 2 个；同目标互斥，停止模拟器先处理在途写入与采集。导航无障碍名称不随任务徽标变化。
迁移与恢复v1 → v2 升级前生成 VACUUM 数据库备份；枚举全部在途 / 待检查任务，不受最近 200 条历史上限影响。中断采集保留并封口已有字节，不重放任务；AVD 提交恢复复核任务归属与配置根目录。
应用过滤边界：无法可靠归属的隔离进程不纳入。PID 刷新间隔可能遗漏新进程的初始日志，集合变化会明确记录缺口。本轮验证包含 10 秒真实采集与短时 GUI 采集，不等同于已完成按小时、高吞吐全链路压力验收。

4. 尚未封板的验收项

  • 实体 Android 手机成功无线配对 / 重连、USB 授权变化、两台物理设备同时在线。
  • 跨显示器 100%—200% 混合 DPI、各贴靠布局与完整窗口状态矩阵。
  • 干净普通 Windows 用户上的零环境引导，以及 NSIS 实际安装、升级、卸载和用户数据保留验证。
  • SDK / AVD / 安装 / 导出各关键点的系统进程强杀、磁盘满、断网 / 代理等完整故障注入矩阵。
  • 按小时持续采集、真实 5,000 行 / 秒输入下 UI + ADB + 磁盘压力与内存 / CPU 基线。
  • 代码签名证书、签名发布包与发布更新流程。

结论：M4 核心功能本轮已落地，本机证据已形成；M4 全量完成与 PRD 全部 P0 通过尚不能宣称。
