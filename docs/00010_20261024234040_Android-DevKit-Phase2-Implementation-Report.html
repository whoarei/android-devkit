已完成本地构建、Rust 回归、隔离模拟器主流程、提交点中断恢复及桌面 WebView 验证。实体手机验收仍待执行，不能以模拟器或桌面测试代签。范围基线见 二期范围。

1. 已交付能力

范围当前实现结果与限制
P2-01 / 02
分包安装		多选 APK / 导入目录；不可变暂存与摘要；包名、versionCode、签名证书、base、重复 split、依赖与 API / ABI 校验；一次 install-multiple -r 任务，安装后复查版本与完整 split 集合。默认保留应用数据，不自动卸载或降级；依赖使用现有 Build-Tools / Java 计划与许可确认。AAB、APKS、APKM、XAPK 容器不在本期。
P2-03 / 04
录屏		默认 30 秒，1–180 秒；静音 MP4，原始 / 最长边 1280 的降分辨率；状态、时长、停止；只向核验 PID 与输出路径的本任务进程发停止信号。完整取回、MP4 索引与视频采样、大小及可用的 SHA-256 校验后才清理设备原件；待保存文件可播放、另存、清理。应用强退后可手动取回原视频，不重新录制。内嵌预览上限 64 MiB，大于此值另存后播放。
P2-05 / 06
文件传输		Download / Pictures / Movies / DCIM 浏览、上级、刷新、名称 / 类型 / 大小 / 时间、多选、拖入上传；多文件 / 多目录、任务队列、按验证字节更新进度与取消。只访问允许的共享存储，不跟随链接或绕过私有目录。单次至多 256 个顶层项目、10000 个条目、4 GiB；Windows 不支持的文件名与大小写冲突明确拒绝。
冲突与恢复同名目标必须明确选择保留、重命名或替换；发布前复核内容指纹。整棵目录按根替换，不合并。原件备份保留到全部发布完成，中断可恢复被替换目标。外部修改时拒绝覆盖；带原件备份的暂存不能被普通清理删除；原件尚未处理的任务记录也不能删除，保留恢复入口。设备无摘要能力时报告仅校验大小；无法核对旧目标摘要时拒绝替换，仍可保留或重命名。
P2-07
统一任务		冻结 serial / transport / ADB 代次；requestId 幂等；同设备资源串行；未知结果标为待检查；重连不自动转投或重放。文件中断后重新选择清单；录屏中断后取回原件。任务保留已发布项目、暂存位置、备份归属与错误详情。

4. 桌面交付待验与保留边界

  • Windows 系统文件 / 多目录选择与“另存 MP4”原生对话框需做人工交互验收；本轮桌面自动化直接提供 QA 路径，实际复制、摘要、缓存与恢复逻辑已验证。
  • 下一次安装版 / 便携版正式构建后复核三项入口与中文 / 英文窄屏操作；本轮没有发布新版本或移动 v0.4.0 标签。
  • 一期已暂缓的干净系统、完整硬件 / 品牌 / 混合 DPI、长时压力与 Authenticode 矩阵继续留在 一期 TODO，本轮不恢复其实施范围。
  • 不支持容器 APK 导入、音频 / 投屏 / 长录屏、root / 私有数据、断点续传 / 同步与跨设备批量操作；保留既定二期排除项。
