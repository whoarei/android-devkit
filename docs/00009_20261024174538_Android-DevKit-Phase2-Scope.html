二期范围与验收基线：真机使用效率

二期主线已确定：分包 APK 安装、录屏、文件传输。
按用户明确选择形成范围基线。继续面向 Windows 11 x64 与本机 Android 设备，复用一期的目标、计划、任务和产物机制；三条功能主线已在当前源码实现，自动验证与桌面 / 隔离模拟器证据见二期实施与验收报告；实体手机验收仍待执行，二期最终实机验收尚未签署。

1. 一期基线与二期目标

一期已发布 v0.4.0，8 个资产及更新签名已核验。 发布候选提交为 bbd25a84a8c3e9fa1241cbc4ce035805f4a3209a。

二期围绕三条日常操作：把拆分 APK 安装到指定手机、录下复现过程、在电脑与手机之间传递测试文件。完成标准是每条流程都有明确结果、可保存材料与异常恢复路径。

2. 本期纳入范围

编号能力交付边界
P2-01分包识别与预检选择多个 .apk 或包含 base / split APK 的目录；核对包名、版本、签名、重复 split 与目标 API / ABI，展示完整安装集合。缺少 base、混入其他应用或签名不一致时拒绝提交；工具缺失沿用最小依赖与许可计划。
P2-02一次分包安装任务在同一安装会话提交 base 与所需 split，沿用冻结目标、计划与 requestId 幂等规则。保留原应用数据，不逐个独立安装、不自动卸载旧应用；安装后复查版本与已安装 split，断线结果不确定时标记待复查。
P2-03录屏开始与停止从明确选定的设备开始录制，显示录制状态、倒计时和停止按钮；默认 30 秒，可选 1–180 秒。首轮为无音频 MP4，提供原生 / 降低分辨率选项；停止仅作用于本任务拥有的录屏进程。
P2-04视频回收与保存正常停止后校验并拉取视频，进入待保存文件，提供预览或另存入口。仅在本地完整保存后清理本任务的设备临时文件；中断保留证据并提供复查，不自动重新录制，不把损坏文件提示为成功。
P2-05共享存储文件浏览浏览设备允许访问的 Download、Pictures、Movies、DCIM 等共享目录，显示名称、类型、大小与修改时间；支持刷新、路径导航和多选。拒绝链接越界与路径穿越，不提供 root、私有数据或受限目录绕过。
P2-06文件上传与下载支持多选文件 / 目录、拖入上传、队列、进度和取消。覆盖前展示冲突并明确选择，默认不覆盖；使用受控暂存与完成后发布，失败 / 取消不留下冒充完整文件的目标，清理仅限本任务暂存。
P2-07任务与连接恢复三项能力复用任务中心、明确目标和资源占用规则；断线不改投，重连不自动重复安装、录制或覆盖文件。传输结果显示大小核验与摘要核验级别，设备不支持摘要时如实说明；操作错误保留可定位原因。

4. 验收标准

编号验收项通过条件
P2-AC-01分包正常与异常安装隔离应用完成 base + split 安装、覆盖升级与数据保留；不同包名 / 版本 / 签名、缺少 base、重复 split、ABI / API 不兼容等集合被预检或设备明确拒绝，原应用不被自动卸载。
P2-AC-02录屏与回放完成 10 秒和 180 秒录屏、提前停止与低分辨率回退；导出 MP4 可在普通播放器回放，状态和实际文件一致。验证编码失败、旋转、锁屏或权限限制时的明确反馈。
P2-AC-03文件往返与冲突文件 / 目录往返传输的内容与命名一致，覆盖中文、空格、空文件与多文件队列；显式覆盖、保留旧文件与重命名分支正确。可摘要校验的测试文件 SHA-256 一致。
P2-AC-04目标与幂等保护两台隔离模拟器同时在线；切换默认设备、断开原连接、重用 transport 或改变 ADB 代次后，计划不改投。重复 requestId 不重复安装或新增录屏；资源冲突按统一队列 / 锁处理。
P2-AC-05中断与保存失败覆盖安装结果落库前中断、录屏停止 / 拉取前后中断、文件提交点强杀、磁盘满与权限失败。结果不确定则待复查，不自动重放；完整旧文件、已有采集材料与可恢复暂存被保留。
P2-AC-06权限与目录边界可访问共享目录工作正常；越界、符号链接、无权限、文件变更与无效文件名有明确处理。清理不会触及用户其他视频、文件或应用数据。
P2-AC-07实机与交付至少一台登记的 Android 手机，经 USB 与无线调试分别完成三项主流程；安装版 / 便携版、中文 / 英文与窄屏交互验证通过。记录手机型号、系统、ADB 版本和实际能力，不以模拟器替代实机回放及存储权限验收。

5. 必须实机验收的最小集合

  1. 分包：在登记手机上安装、覆盖升级并启动隔离样例应用，核对实际 split 集合与原数据保留；记录 USB / 无线两种连接结果。
  2. 录屏：实际手机录制 10 秒 / 180 秒并提前停止，导出回放检查方向、可播放性及设备编码能力；确认本轮不录制音频。
  3. 文件：实际共享存储的中文与空格文件 / 目录往返、覆盖冲突及断线反馈；确认无法访问的目录不会被伪装为空目录。

优先选择一台可用无线调试的 Android 11+ 手机覆盖上述最小流程；实际能力按设备探测与登记结果处理。双目标及强杀边界可用隔离模拟器自动化。这里覆盖二期新增功能，不自动恢复一期所有品牌 / 硬件 / 系统组合矩阵。

6. 技术与结果约束

  • 分包以同一安装会话提交；预检不等于最终成功。任务保存所选文件摘要与 split 清单，执行前检查文件变化，执行后复查安装事实。
  • 录屏只管理明确拥有的进程和临时路径，不使用全局进程终止；先正常封口，再拉取和校验。ADB 会话变化后停止自动动作，已有视频和远端任务信息留供复查。
  • 上传 / 下载按本任务暂存、核验和发布处理；覆盖基于明确冲突选择，清理仅删除拥有证明充分的暂存。显示真实校验等级，不把只有大小核对的传输描述为摘要已验证。
  • 首次缺少依赖时沿用现有最小环境计划、来源校验与许可确认。实现阶段再固定 MP4 检查、签名提取及跨 ADB 版本进度解析方式。

一期 TODO 中长时压力、全量真机 / 干净系统 / 多显示器 / 硬件矩阵和 Authenticode 继续保留；本期新增功能的局部自动回归与上述最小实机集合是二期验收条件。

8. 依据与说明

产品方向由用户明确选择，功能分阶段范围与验收条件为本轮形成的基线。原 PRD 的 P1 设备管理方向列有分包安装、录屏和文件传输。底层能力参考 Android 官方 ADB 文档中的多 APK 安装、screenrecord 和 push / pull；本期将录屏产品上限定为 180 秒且不提供音频。bundletool 官方文档中的 .apks 部署仅作为后续容器支持依据，本期不引入。
