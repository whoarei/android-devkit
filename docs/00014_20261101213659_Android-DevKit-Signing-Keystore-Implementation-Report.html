签名与 Keystore 实施与验证报告

当前源码已实现登记、新建、证书查看与导出、APK 校验及比较、单 APK 签名、结果保护与安装衔接。已纳入 v0.7.0 发布，安装包、便携包与更新资产由现有 CI 构建并校验。本文区分实现范围、自动测试和未实测场景。

依据：产品与实施方案。首版 T-01～T-07 取消决定继续生效，本轮没有恢复这些待办。

表单调整：以密码框内的小眼睛替代“显示本次输入”复选框，各字段独立显隐并在关闭后重置；APK 文件输入与两个操作按钮等高对齐；重签确认简化为“覆盖原签名”。签名页检查结果精简为包名、版本与状态，完整签名及证书信息通过“查看签名详情”转到校验页，保留同一文件和检查结果。

确认页改为文件与密钥分组，突出输出位置；已移除“证书与执行详情”及其全部长信息，仅保留简要文件、目标和密钥。新增独立的“覆盖源文件”选项，勾选后跳过输出选择；确认按钮明确为“签名并覆盖”，验证后替换当前 APK。已取消 APK 输出必须为新绝对路径的限制，支持选择已有输出并在确认后替换；相对路径自动规范化。

2026-11-02 试用调整：工具环境改为标签栏旁的单个图标，正常显示灰绿色扳手，缺项或读取失败显示警示图标，检测时显示加载图标。移除大卡片、常驻文字、下拉箭头和配置按钮；鼠标移入图标即展开详情，移入弹框保持，离开两者时收起，点击外部或按 Esc 也可关闭。保留触屏点击与键盘操作，鼠标点击已展开图标不闪关。详情删除重复说明，仅保留工具状态与缺项入口，不再从签名页直接打开 Java 扫描弹窗。

已交付能力

范围当前行为
SK-01 / SK-02 · 登记与查看引用原 Keystore，保存用途、包名、备注及公开证书快照；同路径重复登记打开原记录，缺失或变化标为待复查。识别 JKS / PKCS12，多 alias 明确选择，纯证书条目不能签名；移除登记保留原文件。
SK-03 · 新建默认 PKCS12 / RSA 3072 / SHA256withRSA / 10950 天，可选 JKS 及独立私钥密码。核对计划后生成、重新打开核验、无覆盖另存并登记。恢复后重新核验同一个结果，不自动生成替代密钥。
SK-04 · 证书显示主体、颁发者、有效期、算法及位数；复制 SHA-1 / SHA-256 的冒号或连续格式；导出 PEM / DER 公开证书，读取独立证书供比较。
SK-05 · APK 校验结构化展示未签名、验证通过或失败、签名方案、签名者、错误及警告；比较证书 DER 的 SHA-256，过期快照或复杂谱系给出无法确定。角色备注不影响证书比较。
SK-06 · APK 签名签名前检查输入与密钥，已有签名需明确同意替换；短时快照、对齐、签名、官方验证及对齐检查后发布结果。支持新文件与已有输出覆盖；独立勾选“覆盖源文件”可跳过输出选择，确认后替换源 APK，目标内容变化时拒绝覆盖。拒绝分包、多签名者及轮换谱系的写入。
SK-07 · 任务与结果接入任务中心、取消、受保护结果与启动恢复；提供另存、打开目录和进入现有安装面板。未保存新密钥不能被普通批量清理删除；已保存密钥的加密缓存有专用清理入口。
集成主导航、中英文、亮暗主题、紧凑布局、原生拖入、导航偏好、IPC 权限与生成合约已接入。沿用最小化及关闭隐藏到托盘、完整退出检查任务与未保存结果的规则。

实现与数据边界

  • Rust 使用专用敏感类型，密码不支持调试输出或序列化；通过 stdin 进入工具，结束尽量清零。密码不进入操作参数、计划 DTO、SQLite、日志、命令行或环境变量。未执行计划授权限时 5 分钟，同 requestId 重复提交返回同一任务。
  • 自有 Java 17 桥调用 SDK 内官方 apksigner.jar 的 ApkSigner / ApkVerifier；Keystore 用 Java API 结构化读取、keytool 生成。运行无需 javac，不分发第三方签名库副本。桥源码和编译类由哈希清单关联。
  • JKS 新建后通过标准 Java API 重新封装并核验真实 Unicode 密码，解决 keytool 重定向 stdin 对字符的解释差异。PKCS12 新建在实测运行时仅允许 ASCII 密码；页面提示需要中文密码时选择 JKS。
  • 新增 SQLite 登记表，只保存路径、用户备注与公开证书。签名任务使用带摘要的加密容器与 APK 短时快照，任务结束清理；敏感缓存目录限制当前用户及 SYSTEM 访问。
  • 新文件输出在目标父目录暂存并以不替换方式发布；选择已有输出或显式覆盖源 APK 使用 ReplaceFile 与同目录短时原件备份，发布前核对目标摘要，失败或中断保留原件或恢复材料。恢复不重放签名，也不使用外部变化的备份覆盖结果；未处理的覆盖恢复材料保护对应任务。新密钥提交日志及明确放弃标记继续支持恢复。
  • 保存成功后应用仍保留加密结果副本，并显示专用清理入口；清理副本不修改用户已另存的 Keystore、登记记录或已保存输出路径。普通产物清理不能删除未保存的新密钥。

主要模块：签名界面 · 工具与证书模型 · 敏感计划、任务与恢复 · IPC 与文件操作 · Java 桥源码。

当前限制与未实测项

本轮不含 AAB / 整组分包签名、多个签名者写入、轮换谱系生成、既有容器的密码或 alias 修改、私钥明文导出、密码保险箱、云端同步或商店上传。签名完整性通过和证书相同均不承诺应用可信或能覆盖设备上的版本。

新的轮换谱系样例、所有磁盘耗尽 / 文件锁 / 突然断电组合、原生文件对话框手动操作、所有 Java / Build-Tools 版本和实体手机组合未逐一实测。已有恢复与目标保护回归不能替代这些组合的专项证据；实现保留不支持或无法确定分支，不将它们计为全量验收通过。
