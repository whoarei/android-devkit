入口与主流程

主入口：SDK 管理

将现有 SDK Update Sites 页签调整为“下载源与站点”。上半区为 SDK 下载源，下半区保留“附加更新站点”。

SDK Platforms / SDK Tools 顶部展示当前来源及“更换来源”。用户遇到下载失败时无需离开 SDK 页面查找设置。

辅助入口：设置与任务

设置 → 网络与下载，只显示当前 SDK 下载源，并通过“管理下载源”进入同一配置页面。

任务详情固定显示来源、仓库地址和官方校验结果；下载失败时提供“重试下载”与“更换下载源”。

选择来源→编辑地址（自定义）→检查连接→应用并刷新→重新选择组件→下载、校验、安装
1

选择只产生待应用配置。三张单选卡分别为 Google 官方、腾讯云镜像、自定义源。当前使用项保留标记，页面顶部始终显示已生效的来源。

2

检查所选配置。检查 4 类仓库索引的获取与解析、一个 Windows 安装包地址的可达性。逐项展示结果；检测中禁用来源和输入，地址或名称变化使旧检测结果失效。

3

应用并刷新。连接检查通过后允许应用。存在待安装选择时才弹出确认，明确清空数量；无选择时直接应用。刷新失败则整体回滚，原来源与原目录继续生效。

4

安装前再次确认来源。安装计划展示组件、下载源和官方校验依据。下载完成逐包校验，通过后才进入 SDK 写入步骤。

配置地址与行为
Google 官方https://dl.google.com/android/repository/
新安装与旧配置迁移的默认值。
腾讯云镜像https://mirrors.cloud.tencent.com/AndroidSDK/
主动选择后生效；不根据 IP 自动切换，不在失败时静默改用其他来源。
自定义源填写“源名称”与 HTTPS 仓库根地址，例如 https://sdk.example.com/android/repository/。自动补齐尾部 /。不接受 HTTP、用户名/密码、查询参数、片段或单个 XML 地址。当前设计保存一个自定义源。
切换范围SDK 组件索引、AOSP / Google APIs / Google Play 系统镜像索引，以及相应平台、工具、系统镜像归档文件。包括缺少 SDK 工具时的 Command-line Tools / Platform-Tools 引导下载。JDK、应用更新和第三方附加站点继续沿用自身来源。
代理三种来源均沿用现有“手动代理”配置。留空时直连。检测详情显示实际使用的网络方式。
应用边界暂存新配置与目录快照，成功后一起提交；失败均不改变当前来源。确认弹窗、待安装计划和目录缓存绑定配置修订号，源变化后旧计划失效。
已有 SDK 任务SDK 下载、解压、安装或其他写入任务进行中时，可编辑与检查新来源，“应用并刷新”禁用，文案“SDK 安装任务进行中，结束后可应用”。任务完成后用户手动应用，不后台自动切换。
缓存目录按来源与配置修订隔离。通过官方校验的完整归档可按组件身份与校验值复用；部分下载文件按任务来源隔离，不跨源拼接。

归档的相对路径保留层级，与选定根地址组合。元数据中的 Google 官方绝对地址按同一映射替换；未知跨站绝对地址不直接执行下载。检测不能只请求镜像站首页，也不能把 HTTP 200 的 HTML 错误页视为有效索引。

“官方校验值”的来源独立于镜像

镜像 XML 能用于展示目录，不能单独证明校验值来自 Google。只有从 Google 官方 HTTPS 仓库取得并独立保存的记录，或随应用可信发行包附带的官方记录，才可作为安装校验依据。
官方记录状态界面文案允许行为
官方可访问，记录获取成功官方校验记录已就绪保存来源、获取时间、组件 ID、修订版本、操作系统、归档路径、体积、算法与校验值。下载后核对实际字节。
官方不可达，已有可信本地记录使用已保存的官方记录与所选组件身份及版本完全匹配时，继续从选定镜像下载并使用该记录校验。
官方不可达，所选版本无记录缺少官方校验记录允许浏览镜像目录与切换来源；阻止缺记录组件的安装计划，提供“重新获取官方记录”。已有记录组件仍可安装。
镜像的组件版本、归档或校验字段不匹配与官方记录不一致，暂不可安装不使用镜像值覆盖官方记录；显示具体组件与版本，等待同步或更新官方记录。
下载字节校验不符安装包校验失败，已停止安装不解压、不安装；隔离或删除失败缓存。重试仍使用原任务来源；更换来源需生成新任务。

算法按 Google 对该归档公布的 SHA-1 / SHA-256 记录使用，不把“存在一个校验字段”当成校验成功。详情页展示算法与期望值；默认页面只保留用户需要的结果和操作。

实现阶段需要落实的边界
  • 当前普通组件安装调用官方 sdkmanager，添加镜像到 repositories.cfg 不能证明安装归档会走镜像。实现时必须统一控制四类索引与归档传输，并保留许可、依赖、组件注册与官方校验过程。
  • 通过应用受控下载层或经过验证的 SDK 工具源适配完成镜像安装；验收须观察真实归档请求地址，不能只凭目录列表通过。
  • 官方校验记录更新属于独立请求；镜像目录与归档始终使用选定来源。官方请求失败时复用可信记录，不把镜像内容升级成官方记录。
  • 重定向保持 HTTPS，限制可接受的目标；日志记录实际来源。新任务固定配置快照，配置保存与目录刷新不得产生新旧来源混用。
  • 附加站点继续使用现有自定义仓库能力；与内置包 ID 冲突的处理继续遵循现有规则。自定义镜像根地址与附加 XML 站点在设置模型、校验和文案中分开。

异常状态与恢复动作

触发条件展示位置与文案恢复动作
自定义地址不合法输入框下逐项说明，例如“请使用 HTTPS 地址”“这里填写仓库根目录，不是单个 XML 文件”。修改地址。旧的连接检查结果立即失效。
一个或多个索引超时 / 404 / 解析失败检测结果逐项失败；显示“当前仍使用 ××，配置尚未切换”。应用按钮禁用。当前方案要求 4 类索引均可用。重试、修改地址或检查既有代理。不中途静默回源。
检测通过但应用刷新失败“刷新失败，已保留原下载源与目录”。保留待应用草稿。再次检查后应用。已勾选组件保持原状态。
存在 SDK 任务来源区提示“SDK 安装任务进行中，结束后可应用”。进入任务中心等待或按既有任务流程取消；任务终结后重新应用。
官方校验记录不足组件行“待补充”，安装计划阻止缺记录组件，保留来源与选择。重新获取官方记录，或选择已有记录的版本。没有跳过校验按钮。
下载失败 / 校验失败任务卡显示固定来源、失败原因；校验失败时明确停止安装。原源重试，或更换源后重新选择组件生成安装计划。

交互与实现验收场景

  1. Google → 腾讯：未应用前顶部来源不变；检查通过后应用，4 类索引与新任务归档均使用腾讯根地址。
  2. 腾讯 → Google：恢复官方来源；旧镜像目录不参与新计划，缓存只在官方身份与校验值一致时复用。
  3. 自定义：尾部 / 自动归一；HTTP、带凭据、查询参数和单个 XML 输入被拒绝；显示完整四类索引地址。
  4. 编辑已通过检查的自定义地址：检查结果立即失效，必须重新检测；不沿用旧地址的成功结果。
  5. 连接检查失败或应用刷新失败：保留原来源与目录；失败状态不改变待安装选择，也不自动切换来源。
  6. 有待安装选择：只在应用时提示清空数量，确认后再失效旧计划；取消确认继续编辑。
  7. SDK 任务进行中：允许编辑、检测，阻止应用；任务来源快照可在任务详情查看。
  8. 官方不可达：有可信缓存记录的版本仍可下载与安装；缺少记录的新版本只允许浏览。
  9. 提供伪造镜像校验字段或损坏归档：安装停止，不以镜像值覆盖官方值，不提交 SDK 包注册。
  10. 安装工具缺失的首次引导也使用选定来源；SDK Platforms、SDK Tools 与创建模拟器依赖安装保持一致。
  11. 附加站点仍使用自身 URL；镜像切换不重复注册同一内置包、不改写全局 Android Studio 配置。
  12. 窗口宽度 1024 / 736 / 320 px 和明暗主题下，主要按钮与地址无裁切；键盘可选择来源、操作弹窗和返回。
