1. 完成的功能

  • 首次 SDK 发现、显式选择复用或新建，显示来源、工具路径、可写状态与可用空间。新配置默认当前用户 %LOCALAPPDATA%\Android\Sdk，旧保存路径保留。
  • 默认设备目标持久保存，不在线时不自动改投；列表方向键、Home / End、Escape；复制设备标识与 AVD 完整路径。
  • 环境摘要默认脱敏，先预览再复制，不产生待保存文件；失败不提示成功。
  • 启动超时后继续等待，不重新创建实例；显式“就绪后安装 APK”、超时及取消；识别后冻结连接，拒绝断线替换、服务代次变化和歧义目标。
  • AVD 按需统计已分配空间，限制时间 / 文件数并跳过链接；删除计划显示释放估算。缓存、SDK 安装暂存与 AVD 数据预算按卷合并，计划与执行前检查；创建计划展示加速检测。
  • 实测修复多模拟器下 emulator console 仅靠 transportId 的歧义；核验原连接后同时指定序列号，保留原模拟器与共享 ADB。
