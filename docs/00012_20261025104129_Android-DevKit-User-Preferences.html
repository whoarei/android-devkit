用户配置与状态持久化

Android DevKit · 当前源码设计 · 创建时间（北京时间）：2026-10-25 10:41:29

用户明确选择的使用偏好跨启动保留；实时连接、操作确认和未提交草稿重新确认。界面组件统一通过配置服务读写，新增字段先进入下表和 Rust 模型。

配置模型与唯一数据源

桌面配置统一存放在 %LOCALAPPDATA%\AndroidDevKit\state\devkit.db。ANDROID_DEVKIT_DATA_DIR 可覆盖应用数据根目录，同时隔离业务配置与用户偏好。前端不再将桌面偏好单独存进 WebView。

配置域模型与存储修改入口
运行环境配置Settings → SQLite settings 单例 JSON；包括 SDK/AVD 目录、Java、代理、启动超时、托盘、SDK 站点与通道、下载源及校验开关。沿用已校验的设置、Java 和下载源命令，用户确认应用后保存。新增字段用默认值兼容旧记录。
用户偏好UserPreferences → 同库 ui_preferences(key,json)；每个偏好单独一行，支持原子补丁。preferences_load / preferences_patch；React 组件通过 src/preferences.ts 获取与保存。
原生窗口与缩放UserPreferences.window、zoomFactor，仍在同一偏好表。原生窗口/WebView 事件；前端补丁禁止伪造这些字段。

界面偏好与运行环境配置保持独立的校验和保存边界。切换主题、移动窗口不改变首次环境配置状态，也不使已确认的 SDK/设备操作计划失效。

仅在本次会话保留的状态

状态不跨启动保留的原因
当前设备选中项、transportId、serverEpoch、设备就绪状态、可用空间、组件安装状态来自实时 ADB、SDK/AVD 文件和磁盘；启动后重新检查，避免使用过期状态。
终端 PTY、进程、当前活跃终端、输出缓冲、快捷命令菜单切页保留已有运行会话；退出后不恢复进程或自动执行命令。
SDK 变更篮、创建/编辑 AVD 草稿、Java/下载源未应用草稿未确认的操作不作为偏好；应用后由真实文件或 Settings 保存。
APK/文件选择、远端浏览目录、重命名草稿、覆盖模式、许可与执行确认依赖本次设备、文件指纹和用户确认；重启后重新选择和核对。
无线连接地址/端口草稿、配对码连接上下文会变化，配对码不保存。
搜索词、展开行、分页、待删除选择、预览/弹窗、错误、进度临时工作上下文；重置可避免恢复后看不到数据或误用旧选择。
日志设备/PID/关键词过滤、原始信息开关、暂停、滚动序号、开始采集开关进程与日志边界会变化；原始信息和采集开关每次明确选择。

迁移、并发与失败处理

  • 启动时读取旧版 android-devkit.theme、locale、default-target、auto-check-update 四类 localStorage 键，将有效值事务性导入缺失的 SQLite 字段。数据库中的值优先；收到成功响应后才移除旧键。重复导入不会覆盖新值。
  • 旧版已保存的 zoomFactor 行直接沿用。未出现的新字段使用 Rust 默认值；单个损坏字段回退其默认值，其他有效字段继续保留，未知未来字段原样留在磁盘。
  • 所有补丁先校验再在一个事务中写入。原生窗口/缩放与前端偏好按字段更新，互不以旧快照覆盖。前端保存顺序串行化，避免快速修改乱序。
  • 普通控件收到数据库成功响应后更新保存值。数字输入允许暂时为空或越界，但仅保存有效整数。读写失败显示配置错误与重试入口，不显示虚假的保存成功。
  • 窗口移动/缩放事件使用 250ms 空闲合并；关闭和正常退出前同步刷新最后一次窗口状态。普通大小来自 Win32 正常窗口范围，最大化/最小化期间不会误存全屏大小或 -32000 坐标。
  • 恢复时按显示器工作区和当前 DPI 调整大小、限制位置；显示器已断开时居中到可用显示器。恢复前窗口隐藏，避免先闪现默认大小。
  • 纯浏览器预览在配置模块中使用单个 localStorage 对象；该预览存储不是桌面应用的数据源。

新增配置的维护规则与回归

  1. 先在本清单决定“持久偏好 / 应用后的业务配置 / 临时状态”，写明默认值、校验范围和重启行为。
  2. 持久偏好添加到 src-tauri/src/preferences.rs 的模型、默认值和校验；生成 TypeScript 合约与默认值，避免前后端重复维护。
  3. 组件使用 usePreference、useNumberPreference 或显式等待 savePreference；不在组件内自行访问存储。原生字段从相应原生事件接入。
  4. 新增字段补充跨重启与失败用例；修改窗口逻辑补充负坐标、DPI、显示器缺失、最大化与最小化回归。仓库检查禁止配置模块外重新出现 localStorage/sessionStorage 写入。

检查入口：pnpm build、cargo test --manifest-path src-tauri/Cargo.toml --lib、cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings、pnpm test:ui-fixtures。偏好界面专项为 node scripts/run-ui-fixtures.cjs preferences。

本轮验证结果

Rust 全量测试 140 项通过，14 项按原设置跳过；11 组隔离界面回归、TypeScript 合约、前端构建与 Clippy 检查通过。旧偏好导入、字段损坏隔离、事务回滚、快速修改和配置读写失败重试均有覆盖。

独立 Windows 应用实例已验证位置移动、正常尺寸调整、最大化退出恢复、还原后的正常边界、最小化退出后可见启动，以及从最大化状态最小化后重新以最大化启动。重启使用全新 WebView 配置目录，确认数据来自 SQLite。显示器断开、负坐标与 DPI 调整通过几何单元测试覆盖。
